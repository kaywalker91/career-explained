카드로 접속한 사용자의 한 판이 관리자 기록이 되기까지

이 서비스는 원본과 바뀐 그림을 보고 다른 부분을 찾는 웹 게임입니다. 이용자는 NFC 카드를 휴대폰에 가까이 대 게임으로 들어가고, 로그인한 뒤 판을 선택해 플레이합니다. NFC는 가까이 댄 카드의 정보를 읽는 통신 방식입니다. 이 프로젝트에서는 카드 발급·접속과 플레이할 수 있는 횟수를 연결하는 데 쓰였습니다. 도전권은 한 판을 시작할 수 있는 기회이고, 포인트는 플레이 결과에 따라 받는 보상입니다. 서비스·역할 근거

휴대폰 브라우저는 그림을 보여 주고 터치를 받는 클라이언트입니다. 서버는 로그인한 사람이 누구인지, 그 사람이 해당 판을 할 수 있는지, 횟수와 포인트를 어떻게 반영할지 판단합니다. 관리자는 웹 화면에서 그림을 발행하고 상품·카드를 관리하며 플레이 기록을 확인합니다. 따라서 관리자 발행 → 휴대폰의 그림 수신 → 판 시작·플레이 → 서버 정산 → 관리자 기록의 흐름을 함께 봐야 합니다. 서버·관리자 기능에는 JavaScript와 Node.js를 사용하고, 데이터 보관에는 Firestore와 파일 저장소를 사용하는 경로가 있습니다.
